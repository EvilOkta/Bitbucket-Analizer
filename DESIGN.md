# Design System: Bitbucket Analyzer (Minimalist Engineering)

## 1. Visual Theme & Atmosphere
**Aesthetic Philosophy:** «Precision Dark Engineering Studio».
Интерфейс спроектирован как высокоточный аналитический инструмент для инженеров и архитекторов: спокойный, собранный, с выверенной типографикой и строгой визуальной иерархией.
Вместо нагромождения разноцветных бейджей, размытия фонов (`backdrop-blur`) и светящихся теней (`glow`), интерфейс опирается на **структурную сетку**, **тонкие монохромные разделители (1px borders)** и **глубокую контрастность нейтральных оттенков**.

* **Density (Плотность):** Balanced Enterprise (Уровень 6 из 10) — эффективное использование экранного пространства без ощущения скученности.
* **Elevation & Depth (Глубина):** Flat & Layered Borders — отказ от псевдо-объёмных теней в пользу разницы яркости подложек (Zinc-950 → Zinc-900 → Zinc-850) и субтильных бордеров `rgba(255, 255, 255, 0.08)`.
* **Motion (Динамика):** Restrained Micro-transitions (150ms cubic-bezier) — мгновенная отзывчивость без визуального шума.

## 2. Color Palette & Functional Roles
Строго **один функциональный акцент** (Precision Cobalt Blue) и нейтральная основа Zinc с калиброванными уровнями контраста.

### Базовая нейтральная палитра (Zinc Scale)
- **Deep Void Background** (`#090A0F`) — Основной фоновый цвет всего приложения. Не абсолютно черный `#000000`, а глубокий графитовый оттенок.
- **Surface Canvas** (`#111318`) — Подложка бокового меню (Sidebar), шапки и модальных окон.
- **Elevated Card / Row Surface** (`#161922`) — Фоновые плашки карточек, элементов списков и инпутов.
- **Elevated Hover Surface** (`#1E222D`) — Интерактивное состояние при наведении (Hover).
- **Hairline Border Subdued** (`#1E2330` / `rgba(255, 255, 255, 0.06)`) — Тонкие структурные разделители, рамки таблиц и карточек.
- **Border Interactive / Focus** (`#2E3748`) — Рамки активных элементов и полей ввода.

### Типографическая палитра (Text Hierarchy)
- **Primary Ink** (`#F1F5F9` / `Slate-100`) — Заголовки, ключевые значения метрик, имена репозиториев и эндпоинтов (100% чёткость).
- **Secondary Body** (`#94A3B8` / `Slate-400`) — Основной текст, описания, пути к файлам.
- **Muted Label** (`#64748B` / `Slate-500`) — Вспомогательные метки, timestamps, типы параметров.

### Единый акцентный цвет (Brand Accent)
- **Cobalt Accent** (`#2563EB` / `Blue-600`) — Ключевые действия (Primary CTA), активная вкладка навигации, состояние фокуса.
- **Cobalt Subtle Subsurface** (`rgba(37, 99, 235, 0.12)`) — Подложка активного пункта меню и выбранной строки.
- **Cobalt Text / Indicator** (`#60A5FA` / `Blue-400`) — Текстовые ссылки, активные иконки.

### Семантические индикаторы (Использовать точечно, без заливок всего блока)
- **Success / Healthy** (`#10B981` / `Emerald-500`) — Статус 200 OK, валидные сертификаты, активный Git-контур.
- **Warning / Divergent** (`#F59E0B` / `Amber-500`) — Версионные расхождения, предупреждения архитектурного аудита.
- **Danger / Security Alert** (`#EF4444` / `Red-500`) — Критические уязвимости, ошибки компиляции/парсинга.
- **Info / Metadata** (`#38BDF8` / `Sky-400`) — Информационные маркеры DTO и Sequence-акторы.

## 3. Typographic Architecture
* **Interface Font:** `Geist Sans` или чистый системный стек (`Inter`, `-apple-system`, `system-ui`, `Segoe UI`).
* **Code & Data Font:** `JetBrains Mono` / `Geist Mono` (для всех DTO, названий классов, сигнатур API, путей файлов и числовых счетчиков).

### Типографическая шкала:
1. **App Header / View Title:** `16px` (`text-base`), `font-semibold`, tracking `-0.01em`.
2. **Section Headings / Card Titles:** `13px` (`text-xs`), `font-medium`, uppercase, tracking `+0.05em`, color `Slate-400`.
3. **Primary Body & Table Items:** `13px` (`text-xs`), `font-normal`, color `Slate-200`.
4. **Captions, Badges, Metadata:** `11px` (`text-[11px]`), `font-mono` для данных или `font-medium` для подписей, color `Slate-400`.
5. **Key Metric Values:** `24px` (`text-2xl`), `font-semibold`, tracking `-0.02em`, color `Slate-100`.

## 4. Component Stylings (Минималистичные паттерны)

### 1. Кнопки (Buttons)
* **Primary Button:** Сплошной цвет `#2563EB`, текст `#FFFFFF`, `rounded-md` (6px), без внешнего свечения (no outer glow). При нажатии: микросмещение `translate-y-[0.5px]`.
* **Secondary / Outline Button:** Прозрачный фон, рамка `1px solid #2E3748`, текст `Slate-300`, hover: фон `#161922`, цвет `#F1F5F9`.
* **Ghost / Icon Button:** Прозрачный фон, hover: `#1E222D`, `p-1.5`, `rounded-md`.

### 2. Карточки и контейнеры (Cards & Panels)
* Замена «тяжелого стекла» (`glass-card`, `glass-panel` с размытием) на плоские панели с чистой геометрией.
* Фон: `#111318` или `#161922`.
* Граница: `1px solid rgba(255, 255, 255, 0.06)`.
* Закругление углов: строго `rounded-lg` (8px) или `rounded-md` (6px). Никаких гипертрофированных `rounded-2xl`.

### 3. Боковое меню (Sidebar)
* Сплошной фон `#0E1015` с разделителем `border-r border-[#1E2330]`.
* Активный пункт: тонкая вертикальная полоска-индикатор слева (`w-0.5 h-4 bg-blue-500`), фон `bg-blue-500/10`, текст `#93C5FD`.
* Неактивный пункт: цвет `text-slate-400`, hover `text-slate-200 hover:bg-slate-900/40`.

### 4. Бейджи и теги (Pills & Badges)
* **Banned:** Разноцветные неоновые заливки с радугой цветов (фиолетовый + бирюзовый + желтый + розовый на одном экране).
* **Minimalist Rule:** Монохромная база (`bg-slate-900 text-slate-300 border border-slate-800`). Цветовой акцент передается только маленькой точкой-индикатором (dot `w-1.5 h-1.5 rounded-full`) или текстом цвета категории.

### 5. Таблицы и списки данных
* Строки с разделением через тонкие `border-b border-[#1A1E29]`.
* Четкий контраст колонок: Имя/Метод — `#F1F5F9`, Путь/Тип — `#94A3B8 font-mono`, Описание — `#64748B`.

## 5. Layout Principles & Spacing
* **Базовый шаг сетки:** 4px / 8px (`gap-2` = 8px, `gap-4` = 16px, `p-4` = 16px, `p-6` = 24px).
* **Контейнеры:** Внутренний скроллинг только для рабочих областей, закрепленная шапка и сайдбар.
* **Зонирование экрана:**
  1. Верхний бар (`h-12`) — Контекст (Текущий репозиторий, ветка, статус контура).
  2. Сайдбар (`w-56` развернутый, `w-14` компактный) — Логические разделы без визуального перегруза.
  3. Основная рабочая область — Структурированные карточки и плоские таблицы с максимальной площадью под данные.

---

## 6. Anti-Patterns (Категорические запреты)
1. ❌ **Никаких радужных карточек:** Запрещено окрашивать 6 карточек дашборда в 6 разных ярких цветов (синий, тиловый, фиолетовый, изумрудный, янтарный, циан). Все карточки имеют нейтральный базовый фон с акцентом только на цифрах.
2. ❌ **Никакого тяжелого Glassmorphism с Blur:** Отказ от `backdrop-blur-md` на статических панелях (увеличивает нагрузку на GPU и мылит текст).
3. ❌ **Никаких неоновых Glow-эффектов:** Запрещены тени вида `shadow-blue-500/30` и светящиеся ореолы вокруг кнопок.
4. ❌ **Никаких смайликов/эмодзи в рабочем интерфейсе:** Замена эмодзи в системных статусах на строгие векторные иконки (`Lucide Icons`).
5. ❌ **Никаких искусственных раздутых отступов:** Инженерные экраны не должны требовать бесконечной прокрутки пустых пространств.
